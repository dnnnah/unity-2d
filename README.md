## 💻 Instrucciones para Ejecutar el Proyecto

1. Clonar este repositorio localmente:
   ```bash
   git clone https://github.com/dnnnah/unity-2d.git
   ```
2. Abrir **Unity Hub**.
3. Hacer clic en **Add** (Añadir proyecto desde el disco) y seleccionar la carpeta clonada.
4. Ejecutar la escena principal localizada en `Assets/Scenes/SampleScene.unity`.
